# 원티드 입력용 문안

## 제목
자람마을 — 한 번 만난 옷을 다음 아이에게

## 해결하고자 한 문제
아이가 자랄 때마다 작아진 옷은 쌓이고, 보호자는 다음 사이즈와 계절에 맞는 옷을 다시 찾아야 합니다. 자람마을은 구매 이력을 성장 옷장에 남기고, 아직 판매 전인 옷도 미리 기다렸다가 이어받는 과정을 연결합니다.

## AI 활용 방식 및 결과 (500자 이내)
생성형 AI를 활용해 서비스 기획을 검토하고 React 기반 인터랙티브 프로토타입과 UI를 구현했습니다. 사용자는 예시 옷 분석, 사이즈·얼룩 확인, 판매글 수정, 낱개·소묶음 구매, 특정 옷 기다림, 성장 확인과 재판매를 연속해서 체험할 수 있습니다. AI 분석 기능은 준비된 데이터로 동작하는 시뮬레이션이며 실제 모델 API를 호출하지 않습니다. 확인 답변에 따라 설명과 제안 가격이 바뀌고, 거래·기다림 이력은 현재 브라우저에 저장됩니다. 실제 서비스에서는 사진 정보 추출에 AI를 제한적으로 사용하고 조합·할인·알림은 코드로 처리하는 구조를 설계했습니다.

## 사용 도구
실제로 사용한 범위에 한해 ChatGPT, React, Vercel 선택. 서비스 런타임 AI SDK·Supabase 등 구현하지 않은 도구는 선택하지 않습니다.

## 권장 화면 5개
홈 추천 / 특정 옷 기다림 상세 / 사이즈·얼룩 확인 / 선택 구매·할인 / 성장 옷장·재판매. 16:9 비율 캡처가 요구됩니다. 실제 배포본을 기준으로 제출 전 최종 촬영합니다.

## 체험 범위
실제 모델 호출, 결제, 배송, 메시지와 서버 업로드 없음. 사진은 로컬 미리보기만 제공. 예시 상품·인물·거래기록 사용. 임시저장과 제출은 아직 하지 않음.
