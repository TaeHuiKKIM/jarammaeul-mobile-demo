# 중고 의류 사진·안내 문구 개선

## 요청
새 상품처럼 연출된 의류 사진을 일반 가정에서 촬영한 중고 아동복 사진으로 교체. 사용 흐름에 불필요한 체험 안내·초기화 문구 제거.

## 반영
- 자연스러운 구김, 세탁감, 보풀과 작은 사용 흔적이 있는 의류 사진 생성.
- 상품 종류와 사진의 순서를 맞춘 3×2 이미지 두 장 사용.
- 홈 하단 ‘체험 안내 및 처음부터 시작’ 및 PC의 체험 안내 버튼 제거.
- 구매 버튼은 ‘내 옷장에 담기’, 기다림 버튼은 ‘판매 소식 확인’으로 정리.
- 분석 시작 위치에 예시 시뮬레이션임을 한 번 안내. 실제 결제가 없다는 구매 확인 문구 유지.
- 기존 사진 파일은 보존하고 새 파일명으로 참조해 캐시 충돌 방지.

## 회귀 확인
동일 React 소스를 Sites/Vercel로 빌드. 검색·찜·기다림·등록·옷장 기능 유지. 사진은 실제 이용자 매물이 아닌 생성한 예시 이미지.
