# 원티드 제출용 자람마을 프로토타입

## 설계와 구현계획
기존 초록 위치핀 로고, Pretendard 본문, Jua 워드마크와 모바일 우선 화면을 유지한다. PC에서는 왼쪽에 성장순환 단계와 체험 안내, 오른쪽에 휴대폰을 둔다. 홈은 사진 중심 추천, 기다림은 아직 판매 전인 옷, 옷장은 보유한 옷과 성장 확인을 보여준다.

- 사진 등록 → 단계별 분석 시뮬레이션 → 사이즈·얼룩 확인 → 편집 → 판매 등록
- 낱개/소묶음 선택 → 할인 계산 → 구매 체험 → 옷장 반영
- 특정 옷 기다림 추가/해제 → 판매 준비 알림 → 구매 체험
- 옷장 착용 확인 → 작아짐 표시 → 기존 정보 재사용 → 재판매
- 검색, 사이즈 필터, 찜, 알림, 빈 상태, 초기화 제공
- 분석 시뮬레이션임을 업로드 단계에서 설명한다. 업로드한 사진은 미리보기만 하고 실제 인식했다고 주장하지 않는다.
- localStorage는 이 브라우저의 체험 상태만 보관한다. 결제·메시지·서버 업로드는 하지 않는다.

## 원티드 양식 확인
2026-09-13 크롬에서 실제 접수 양식 확인. 대표 이미지, 제목, 해결 문제, AI 활용 및 결과(500자), 사용 도구, 서비스 링크, 스크린샷 최대 5개(16:9)가 필요. 마감은 2026-09-20. 제출/임시저장은 실행하지 않는다.

## 회귀 예방
기존 정적 Vercel 미러와 React 앱의 별도 관리가 아이콘 누락을 일으켰다. 이번 작업은 React 앱을 기준으로 제작하고 Vercel용 파일도 동일한 클라이언트 번들에서 생성한다. 사용 중인 로고와 12종 의류 이미지 사용. 기존 연구/제출자료는 보존한다.
