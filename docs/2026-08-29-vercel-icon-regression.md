# Vercel 정적 미러 아이콘 회귀 수정

## 증상

- 상세 화면 우측 상단에 하트 아이콘 대신 `찜` 글자가 표시됐다.
- 상단 알림이 벨 아이콘 대신 `알림` 글자로 표시됐다.
- 하단 `홈·기다림·등록·옷장` 메뉴에서 아이콘이 빠졌다.

## 원인

React/Sites 버전은 Lucide 아이콘 컴포넌트를 사용하지만, 별도로 만든 Vercel 정적 미러는 초기 제작 시 텍스트 자리표시자만 넣었다. 이후 두 버전의 시각 계약을 검사하는 테스트가 없어 차이가 남았다.

## 수정

- 정적 미러에 공통 24×24 선형 SVG 아이콘 시스템을 추가했다.
- 상단 알림·뒤로가기·찜을 아이콘 버튼으로 교체했다.
- 하단 네 메뉴에 홈·벨·꾸러미 추가·옷장 아이콘을 복구했다.
- smoke test에서 텍스트 자리표시자의 재등장과 하단 아이콘 누락을 검사한다.
